Rubric: **A4** (14 pts), **A5** (14 pts), and instructor criteria **I1**, **I2**. See [RUBRIC.md](RUBRIC.md).

## 1. Requirement

Run the QA pipeline, stages **01 → 06**, on the exam feature `shopgo-refund`, exactly as the framework
prescribes (`AGENTS.md`, `qa-system/workflows/WORKFLOW.md`, `qa-system/core/QA_STANDARD.md`).

- **Sources**: only `INPUT/shopgo-refund/` (five compartments, read-only) and what you derive from it.
  General domain knowledge, the industry pack and other tasks' outputs are **not** sources
  (QA_STANDARD §10.1, §10.3). The documents in `02_ba/_superseded/` are kept for comparison only.
- **Plan First**: write `OUTPUT/shopgo-refund/00_plan.md` before any analysis (`AGENTS.md` §2).
- **Feature knowledge**: create and maintain `knowledge/features/shopgo-refund.md` as the framework
  requires (QA_STANDARD §8).
- Stop after stage 06. No automation stage.

## 2. ASK gate and questions

- Before writing any stage 03–06 file, run `npm run gate shopgo-refund`. Exit `1` ⇒ the gate is closed:
  do not write stage 03–06 files (QA_STANDARD §1).
- **Answer questions only from the INPUT.** When a newer dated document in the INPUT settles a point
  (QA_STANDARD §10.2), cite that document.
- **When the INPUT cannot answer a question, record the question and do not assume.** Write it as an
  `OQ` (stage 01) / `MR` (stage 02) using the question table of QA_STANDARD §9.4. Never fill in an
  answer, a `Confirmed` status or a §8 decision yourself (QA_STANDARD §1, rule 4). Never invent a value,
  a limit or a message text that the INPUT does not state.
- Raising a precise question is **correct work** and is rewarded. Filling a gap with a plausible value is
  fabrication and loses points.
