# 02_ba — Yêu Cầu Chi Tiết Từ Business Analyst (BẮT BUỘC)

## Mục đích
Nguồn chính của logic nghiệp vụ để trích `BR-xx`/`FD-xx`/`AF-xx`, quét kẽ hở 06W và thiết kế test case.
Khi khác các ngăn khác, thứ tự ưu tiên theo `qa-system/core/QA_STANDARD.md` §10.2 (CR/Q&A có ngày mới hơn thắng phần nó nói tới).
Ghi version/ngày trong tên file để agent biết bản nào mới nhất.

## Các loại tài liệu phù hợp:
- PRD (Product Requirement Document)
- SRS (Software Requirement Specification)
- Danh sách User Stories & Tiêu chí nghiệm thu (Acceptance Criteria - AC)
- Use Case Specifications & Luồng nghiệp vụ (Workflows)

## Định dạng:
- `.docx` (Hệ thống sẽ tự động chuyển đổi ngầm sang `.md`)
- `.md` (Khuyến nghị chuẩn)
