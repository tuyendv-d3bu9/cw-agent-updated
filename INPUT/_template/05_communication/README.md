# 05_communication — Meeting Notes, Q&A & Change Requests

## Purpose
Holds exchanges and requirement clarifications between Tester, BA, Dev and the Customer. A CR, Q&A or meeting note that is **dated** and newer than the spec wins for the part it covers (`qa-system/core/QA_STANDARD.md` §10.2). No date ⇒ the agent asks the BA instead of choosing.

## Suitable document types:
- Meeting minutes
- Q&A logs clarifying requirements with the BA/PO
- Change Requests (CR) raised midway
- Excerpts of Slack / Teams / Email messages where a Stakeholder confirms a rule

## Formats:
- `.md`, `.txt`, `.docx`
