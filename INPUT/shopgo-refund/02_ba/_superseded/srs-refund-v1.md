# Software Requirements Specification — Order Refund Request

Version: 1.0

Date: 2026-09-15

## 1. Scope

This feature lets customers submit a refund request for an order purchased on ShopGo.

## 2. Business rules

R1. Only orders in status Delivered can have a refund request submitted.

R2. The request must be submitted within 5 days from the date of successful delivery.

R3. All refund requests are approved by a CS Agent.
