# Domain packs · reference register

> One register for every pack, because several references (ISO/IEC 25010, OWASP ASVS, ISTQB, PCI SSC) are shared.
> Pack files cite a row by its `Ref id` in their `Source` / `Reference` column; `Unknown` means no verified reference.
> A reference is evidence for **what the page says**, never for a project rule (QA_STANDARD §10.3).
> Paraphrased in one line; no text is copied. Verification date for every row: **2026-11-19**.

## Status meaning

| Status | Meaning | What a pack may cite |
|---|---|---|
| VERIFIED | The specific content in "What was read" was read on the page itself | Only that content |
| PARTIAL | An overview / index / chapter title was read; the detail sits behind a paywall, login, licence or an unreadable file | Only what the overview says (e.g. that a chapter exists), never a requirement inside it |
| UNKNOWN | The page could not be accessed (403, login, unreadable PDF) | Nothing: kept only to show the attempt |

## Not verified, not cited

Local laws (consumer protection, tax, AML/KYC, payment regulation, insurance solvency and disclosure, health-data law outside the US)
vary by jurisdiction. No pack states their content; each pack names them only as "local regulation — Unknown" and turns them into a
closed question for the project ("Which `<regulation>` applies to `<feature>` in `<jurisdiction>`?").
